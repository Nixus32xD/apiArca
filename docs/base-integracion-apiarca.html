Conexion API

Estos datos se usan para armar endpoints y headers. En una app real, el token debe vivir en backend o storage seguro, no hardcodeado en frontend publico.

Datos fiscales

Alta o actualizacion de la empresa fiscal que luego va a emitir comprobantes.

Validacion

Usar antes de emitir. Primero status local; despues diagnostics, actividades y puntos de venta contra ARCA.

  • La empresa debe existir y estar habilitada.
  • La credencial activa debe tener certificado vigente.
  • El punto de venta debe estar habilitado en ARCA para WSFEv1.
  • Si el comprobante lleva actividad, debe estar activa para el CUIT emisor.

Homologacion

Flujo recomendado para probar sin tocar produccion: crear empresa con environment=testing, generar CSR, cargarlo en ARCA homologacion y luego subir el certificado devuelto.

Produccion

Antes de emitir en produccion, repetir el onboarding con certificado productivo y empresa con environment=production.

  • APP_ENV=production y APP_DEBUG=false.
  • APP_KEY generado y persistido; no rotarlo sin migracion.
  • FISCAL_API_TOKENS, OPENSSL_CONF y FISCAL_OPENSSL_CONF configurados.
  • Scheduler activo para CAEA: php artisan schedule:run.
  • Diagnostico OK antes de habilitar ventas reales.

Generar factura

Para servicios de una estetica usar concept=2 y completar fechas de servicio. Con invoice_mode=auto, la API resuelve Factura A/B/C.

Si el emisor es monotributo o exento, el comprobante sera tipo C y no debe discriminar IVA. Si es responsable inscripto, puede emitir B a consumidor final o A a responsable inscripto.
Completa los datos y arma el request.

Rutas principales

  • POST/api/fiscal/companies
  • GET/api/fiscal/companies/{company}/status
  • GET/api/fiscal/companies/{company}/diagnostics
  • POST/api/fiscal/companies/{company}/credentials/csr
  • PUT/api/fiscal/companies/{company}/credentials/{credential}/certificate
  • POST/api/fiscal/documents
  • GET/api/fiscal/documents/by-origin
  • POST/api/fiscal/documents/{document}/reconcile
  • POST/api/fiscal/documents/{document}/retry
